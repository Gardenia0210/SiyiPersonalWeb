Thingdom is a role-play–based intelligent educational toy that transforms children into “Little Diplomats,” enabling natural second language acquisition through everyday exploration.

01 / OPPORTUNITY

From learning words

to using them.

Storybooks, apps, tutors and flashcards offer input. Thingdom explores how everyday objects can become opportunities for spontaneous speech.

For children

Agency, expression and physical exploration make speaking part of a story.

For continuity

Vocabulary matched to ability returns through adaptive dialogue and spaced repetition.

For parents

Clear progress, practical guidance and boundaries make learning legible.

How might we

invite children to speak through playful, adaptive exploration—and keep progress visible to parents?

03 / SYSTEM

Demo Video

The architecture connects hardware, a Django backend and a parent-facing frontend. A physical interaction moves through sensing, contextual response and learning feedback.

Overall Technical Architecture

01 / Hardware

Raspberry Pi 5, camera, pressure sensor and GPIO buttons connect the child’s actions with the system. YOLO11n detects objects; DashScope transcribes speech.

02 / Backend

EMQX carries MQTT requests and responses. Django routes events to agent services and stores learning and conversation data in PostgreSQL.

03 / Frontend

The Parent App supports accounts, device binding, dictionary selection, study plans, vocabulary progress and conversation history.

Overlap is not always enough.

Generate Contextual Object Identities

naming_agent.py

The naming agent sends the detected category and chapter context to the configured GLM model. A Pydantic NamingAgentResponse validates bilingual identity names and descriptions. 

Persist Character Personality

object_persona.py

A conversation receives one of twelve persona identifiers, which Django stores with its object identity. The corresponding Markdown template is loaded into the dynamic system prompt. 

Compose Adaptive Dialogue And Short-Term Memory

main_agent.py

LangChain create_agent combines character, curriculum, child memory and guardrail middleware. GLM generates MainAgentResponse structured output. The streaming entry emits decoded dialogue and structured vocabulary identifiers.

Prioritize Vocabulary For Adaptive Teaching

StudyMiddleware._query_candidate_words

Django queries vocabulary from active study plans, excludes frozen and mastered entries, and orders candidates by review priority. 

Assess Vocabulary From Actual Child Replies

word_mastery_agent.py

The assessment agent receives the actual AI sentence, child transcription and eligible word records. GLM returns recognition, usage, fluency and confidence per word.

Advance Mastery And Schedule Review

_process_word_mastery、_advance_learned_type

Recognition:40%, Usage:40%, Fluency: 20%

Passing requires confidence of at least 0.55 and mastery of at least 0.65.

Summarize Encounters Into Long-Term Memory

mqtt_handlers.py

The handler gathers encounter messages, mastery evidence and existing memory, then invokes the summary agent. Returned traits, interests, motivation triggers and English level update LongtermMemory for later personalization.

Manage Parent Plans And Progress

views.py

UserStudyPlan and UserOngoingPlan separate chapter selection from per-word learning state, enabling the parent interface to display learned, pending and review vocabulary.

Check Conversation Content

word_mastery_agent.py

Unsafe incoming classifications return a redirecting response and end the current agent path. 

The output middleware reviews generated dialogue with the configured safety model and can replace unsuitable content.
