Fingertale is a community-based rehabilitation game for older adults, combining hand exercises with traditional shadow puppetry. Through Practice, Rehearsal, and Performance modes, players control puppets using hand gestures, collaborate on challenges, and stage performances. The game promotes motor skills, creativity, and social engagement while making rehabilitation enjoyable.

Initialize Native Landmark Models

LoadModelBytes

StreamingAssets model buffers initialize MediaPipe HandLandmarker and optional FaceLandmarker VIDEO tasks through BaseOptions. 

Extract Geometric Hand Pose Features

HandPoseAnalyzer.cs

A 21-landmark IReadOnlyList<Vector3> becomes a HandPose containing finger extension, curl, palm geometry, and orientation features. 

Run Video Inference And Publish Observations

SubmitResult, SubmitFaceResult

The Run coroutine uses asynchronous texture readback and timestamped TryDetectForVideo calls. 

Classify Expected Static Gestures

HandLandmarkGestureClassifier.cs

HandPose predicates classify supported static gestures, including open palm, inverted scissors, pinch, pointing, and dance. 

Recognize Motion From Consecutive Frames

HandMotionGestureRecognizer.cs

Per-frame pose, wrist displacement, and orientation history drive temporal gesture recognition.

Require Stable Poses Before Completion

GestureStabilityFilter.cs

A GestureId candidate must remain stable for the required hold duration. Delta-time accumulation, cooldownRemaining, and requiresNeutral suppress transient or repeated completion.

Combine Recognizers Into Player Gesture Events

HandLandmarkGestureProvider.cs

SubmitHands validates and selects landmark inputs, updates palm position and pinch state, then evaluates special, motion, and static recognition paths. Static results pass through GestureStabilityFilter. Accepted actions emit GestureEvent values carrying player ID, hand side, phase, confidence, and timestamp.
